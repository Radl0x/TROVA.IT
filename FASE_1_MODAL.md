# TROVA — Fase 1: sistema modal condiviso

- Creato `js/modal-system.js` e aggiunto a tutte le 13 pagine HTML.
- CSS condiviso in `css/styles.css`, responsive, chiusura con Escape, overlay, focus trap e ritorno del focus.
- Intercettati i placeholder più comuni di cliente, professionista e admin.
- Moduli demo per proposta, conversazione, segnalazione, profilo e azioni amministrative.
- Azioni simulate registrate in `localStorage` (`trova_modal_actions_v1`).
- Nessun backend, invio reale, verifica o controllo di permessi.
- La fase 2 deve collegare le azioni a un modello di stato condiviso, dati delle schede e flussi CRUD completi.
- Per provare: aprire `index.html` o servire la cartella con un server statico locale.
